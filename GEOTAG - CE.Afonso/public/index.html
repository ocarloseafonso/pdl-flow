🔍 Como verificar os metadados

🪟

Windows Explorer

  1. Clique com o botão direito na imagem
  2. Selecione Propriedades
  3. Clique na aba Detalhes
  4. Veja: Título, Marcas, Autores, Direitos autorais, Tirada em
📋

Arquivo _audit.json

  1. Extraia o .zip gerado
  2. Abra o arquivo *_audit.json de cada imagem
  3. Veja todos os metadados aplicados, o hash MD5, validações de tamanho e as sugestões de legenda para o GMB
🛠️

ExifTool (avançado)

  1. Baixe o ExifTool
  2. Execute no terminal:
    exiftool -all nome-da-foto.png
  3. Todos os campos IPTC e XMP serão listados

⚠️ O Windows exibe Título (IPTC:ObjectName), Marcas (Keywords), Autores (By-line/Creator), Direitos autorais e Tirada Em (DateCreated). Demais campos XMP como altText e gmbCaption ficam visíveis apenas via ExifTool ou no arquivo _audit.json.
